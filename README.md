# Travel Planner

フライト・宿・場所・時差を調べ、行程と地図を作る旅行企画 Agent。問い合わせの下書きと、承認後の連絡も支援します。

## はじめに

Python 3.10 以上と Bash が必要です。同梱 Python ツールは標準ライブラリだけを使用します。リポジトリのルートから `bash bin/hotel --help` のように実行できます。Plugin の同梱・必須指定はありません。

- 旅行検索と地図: `knowledge/travel-search-toolkit.md`
- Gmail の任意設定: `knowledge/gmail-toolkit.md`
- フォーム問い合わせ: `.claude/skills/contact-form/SKILL.md`

外部サービスは利用者自身のアカウント、API 有効化、課金設定、アクセス許可が必要です。認証値は秘密ストアから環境変数へ渡し、リポジトリやチャットへ貼らないでください。検索条件や座標は該当サービスへ送信されます。料金・在庫・利用可能な API は実行時に確認してください。

## 依頼例

「京都で2泊3日、大人2名、予算と移動時間を比較して行程を作って」
「選んだ宿へ空室確認の問い合わせを下書きして」

## 公開版の範囲

個人・会社のメモリ、連絡先、顧客情報、過去の旅行記録、認証設定は含みません。Airbnb の非公式 MCP、ローカル固定パスの fli、利用条件を確認できていない到達圏 API、第三者の find-skills と lockfile は除外しました。メール送信には利用者の承認が必要です。フォーム操作には利用環境が提供するブラウザが別途必要です。

公開準備では構文、ヘルプ、ローカル変換を検証します。外部 API への接続、実在庫検索、Gmail 認可・送信、ブラウザ操作は検証対象外です。
