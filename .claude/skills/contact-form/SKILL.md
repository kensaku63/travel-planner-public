# お問い合わせフォーム

利用環境で許可されたブラウザツールを使用する。特定の CLI、非公開 Plugin、作者の環境には依存しない。ブラウザが無い場合は下書きを渡し、利用者に手動送信を依頼する。

1. `templates/inquiry.md` に相手、用件、日程、人数と利用者から確認した連絡先をまとめる。個人情報を推測しない。
2. 公式の問い合わせページでフィールドを確認し、下書きを記入する。任意の宣伝購読は選ばない。
3. 送信先 URL、全フィールド、本文、同意事項を利用者に提示して明示的承認を得る。
4. 承認された内容だけを送信し、完了画面を確認する。CAPTCHA やログインは利用者へ引き継ぐ。
5. 非公開の作業記録に送信日時・相手・結果を記録する。結果不明のときは再送せず確認する。

詳細は `references/recipe.md`。記入・下書きの依頼だけでは送信しない。
